# PIMX SONIC BOT ⚡🎵🤖

A high-speed Telegram media bot focused on downloading and delivering audio/video content with a practical admin workflow, user tracking, and automatic cleanup.

## Highlights 🔥
- Download pipeline powered by `yt-dlp`
- Supports media-focused Telegram interactions with inline/reply keyboards
- User database with `sqlite3` for tracking and management
- Channel membership gate before full access
- Async + threaded architecture for responsive bot behavior
- Automatic file cleanup queue to keep storage under control
- Minimal logging setup for cleaner operations

## Tech Stack 🛠️
- Python
- python-telegram-bot
- yt-dlp
- aiohttp
- sqlite3
- AsyncIO + threading

## Run Locally 🚀
```bash
pip install -r requirements.txt
python main2.py
```

## Project Goal 🎯
Deliver a fast, stable, and scalable Telegram media bot experience for everyday users.
